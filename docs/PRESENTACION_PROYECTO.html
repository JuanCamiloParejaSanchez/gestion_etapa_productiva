🎯 Objetivos del Proyecto

📌 Objetivo General

Desarrollar una plataforma web integral que optimice la gestión, seguimiento y documentación de la etapa productiva de los aprendices del SENA, mejorando la eficiencia administrativa y la experiencia de usuario.

🎯 Objetivos Específicos

  • Digitalizar el proceso de gestión documental
  • Implementar seguimiento en tiempo real
  • Automatizar notificaciones y alertas
  • Analizar sentimientos con IA
  • Generar reportes estadísticos
  • Garantizar seguridad de datos

🏗️ Arquitectura del Sistema

Presentación (EJS)
Lógica (Express.js)
Datos (MySQL)

🔧 Patrón de Arquitectura

MVC Modular con Separación de Responsabilidades

  • Modelo: Interacción con MySQL mediante Servicios y Repositorios
  • Vista: Templates EJS con layouts reutilizables
  • Controlador: Lógica de negocio y orquestación
  • Middleware: Autenticación, validación y seguridad
  • Servicios: Lógica de negocio compleja (Watson, Correo, Notificaciones)
